# Product

## Platform

web

## Stack

The approved handoff specifies Next.js App Router, TypeScript, Tailwind and shadcn/ui, with FastAPI and FalkorDB. The browser app will deploy separately on Vercel; API/graph/Caddy run on a VM.

## Users and purpose

Open-source maintainers triage incoming issues by inspecting suggested labels, reviewers, past decisions and risks. Keystone's distinguishing mechanism is graph-derived, query-visible evidence behind every factual claim.

## Operating context

The hackathon demo shows a sandbox issue, a triage run, graph evidence, trace, feedback, cited Q&A and measured Proof. B1–B3 currently implement only safe fixture shells, not live graph intelligence or writes.

## Capabilities and constraints

Preserve stable node keys, tenant-separated graphs, public GitHub data without emails, sandbox-only writes and dry-run default. No agent frameworks. Real webhook action, canvas, Proof and deployment are later tasks, not claimed capabilities of this shell.

## Brand commitments

`design/README.md`, `design/tokens.json` and `design/graph-canvas.md` are binding visual authority: granite/amber, Instrument Sans/JetBrains Mono, dark default, three panes, restrained motion, explicit citations and sentence-case copy. No redesign is requested.

## Evidence on hand

The spec/task/design pack and proposed contracts are supplied. Fixture content is illustrative; no measured graph counts, Proof numbers or deployment evidence exist yet. Independent A approval of draft contracts and real data source IDs remain open.

## Accessibility

Visible keyboard focus, non-color status cues, readable text in both themes and stacked phone layout follow the handoff.
