# B3 Fixture Web Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render approved fixture triage in Keystone's dark/light three-pane UI, with tenant navigation, safe dry-run controls and an expandable, copyable Cypher trace.

**Architecture:** A Next.js App Router server page loads T0 JSON and passes typed props to a focused client workspace. Theme and interaction state stay local; fixture mode makes no GitHub or API writes. A canvas placeholder reserves B5's surface without pretending a graph exists, and one loader becomes B4's API switch seam.

**Tech Stack:** Next.js/App Router, React, TypeScript, Tailwind, shadcn/ui, Lucide; proposed Playwright browser tests (approval required).

**Spec:** `docs/tasks.md` B3; `docs/spec.md` section 11; `design/README.md`; `design/tokens.json`; `design/graph-canvas.md`; approved `docs/superpowers/plans/2026-10-14-b1-b3-contract-proposal.md`.

## Global Constraints

- “Dark is the default theme.” Dark values on `:root`, light values on `.light`; `--radius` is `radius-md`.
- “Left, 360px”; “Right, 400px”; centre flexible; panels separated by `space-4`.
- “Below 1024px the canvas moves under the triage card and the trace becomes a drawer. Below 640px the panes stack in reading order: card, canvas (fixed 320px tall), trace.”
- “Dry run is on by default”; on-state button: “Apply to sandbox (dry run)”; off-state: “Apply to sandbox”.
- Instrument Sans weights 400/500/600 and JetBrains Mono 400/500; body 14px; readable metadata at least caption 12px (11px label is reserved for uppercase section labels).
- Amber only for evidence and the one primary action per view; light amber text uses `evidence`, not `primary`.
- No product code before kickoff, no commits, no edits to read-only `design/` or unapproved shared types/fixtures. Ask before dependencies outside the prescribed stack.
- No force graph, real writes, polling, Proof charts, webhook processing or Vercel deployment in B3. Human ticks the task after actual acceptance evidence.

## Review Focus

- Long Cypher/keys/logins: wrap or locally scroll without page-level overflow at phone width.
- Clipboard unavailable/denied: show failure, never a false “Copied” state.
- Empty lists/empty tool results: visible honest absence, not invented recommendations or errors.
- Keyboard/theme storage limitations: all controls usable with visible focus; storage failure does not break rendering.
- Tenant navigation: unknown tenant fails clearly and never reuses another tenant's fixture as live data.
